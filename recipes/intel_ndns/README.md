# Model Recipes

This directory contains recipes for various models used in the Intel NDNS project:

- **cirm_gsn/**: Fullband Gated Spiking Neural Network (GSN) training recipe.
- **sdnn_delays/**: Intel's official SDNN model, adapted for this codebase.
- **spiking_fullsubnet/**: Spiking-FullSubNet training and inference recipe.

Each subdirectory provides scripts and configuration files for training and evaluating the corresponding model.
